--> Function-Based Views (FBVs) in Django are Python functions used to handle web requests and send back web responses.
a.) Each FBV is linked to a specific URL and controls what happens when that URL is visited.
b.) Every view function receives an HttpRequest object from the browser.
c.) The view returns an HttpResponse, which can be HTML, a redirect, or an error page.
d.) FBVs provide a clear and straightforward way to define application logic.

***Django Function Based Views - CRUD Operations***
--> Function-Based Views in Django also support CRUD operations (Create, Retrieve, Update and Delete), allowing you to interact with database models to perform common web application tasks.
a.) Create: create or add new entries in a table in the database. 
b.) Retrieve: read, retrieve, search, or view existing entries as a list (List View) or retrieve a particular entry in detail (Detail View)
c.) Update: update or edit existing entries in a table in the database 
d.) Delete: delete, deactivate, or remove existing entries in a table in the database

--> These operations power common features like user management, blog posts, and product catalogs, making Function-Based Views essential for building dynamic web applications.
