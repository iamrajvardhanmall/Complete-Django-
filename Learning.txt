PART 1: Introduction to Django | Getting started with Django | Installing and using virtualenv with Python 3
A. Django Create Project and Virtual Enviroment

1.) django--admin startproject "yourProjectName"
2.) python manage.py startapp "yourAppName"
3.) python manage.py runserver
4.) pip install virtualenv
5.) virtualenv "yourVirtualEnviromentName"
6.) "yourVirtualEnviromentName"\Scripts\activate
7.) pip freeze > requirements.txt
8.) pip install -r requirements.txt
